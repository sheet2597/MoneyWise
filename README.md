# MoneyWise 💰

MoneyWise is a personal finance management web application built using Python Flask. It helps users manage income, track expenses, and visualize their financial data.

## 🚀 Features

- Add and manage income records
- Track expenses
- Maintain personal financial records
- Database integration for storing user data
- Financial data visualization using graphs
- Responsive user interface

## 🛠️ Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap
- Tailwind CSS

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/sheet2597/MoneyWise.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Database

- Create a MySQL database
- Update database credentials in `db.py`

### 4. Run Application

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000/
```
